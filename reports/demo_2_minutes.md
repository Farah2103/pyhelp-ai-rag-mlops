# Démonstration de deux minutes
Préparer l'environnement et charger le modèle avant l'enregistrement. Le professeur demande une vidéo ou une démonstration réelle ; aucune vidéo n'est générée automatiquement.

| Temps | Action et message |
|---|---|
| 0:00–0:15 | Présenter besoin : support Python 3.11.18, neuf documents officiels sélectionnés ; afficher architecture et inventaire. |
| 0:15–0:40 | Dans l'interface locale, poser « How do I create a virtual environment using venv? ». Afficher réponse, passage et identifiant ; annoncer une éventuelle abstention du petit modèle sans la masquer. |
| 0:40–1:00 | Poser une question hors corpus, puis Python 3.13 ; montrer refus ou limite mesurée. Ne pas promettre un refus universel. |
| 1:00–1:25 | Afficher comparison.csv et MLflow : configurations A/B, rappel FR/EN, paramètres, version modèle. Expliquer la sélection sur dev. |
| 1:25–1:45 | Exécuter pytest et scripts.gates ; afficher workflow CI, manifests et lock DVC. |
| 1:45–2:00 | Montrer monitoring.json, risque d'hallucination malgré une citation, et limite de la génération locale. |

Si un appel échoue : présenter le 503 contrôlé et expliquer la dépendance au moteur ; conserver la vidéo honnête, sans attribuer à un LLM une réponse fabriquée.
