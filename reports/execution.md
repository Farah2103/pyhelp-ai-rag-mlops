## Distinction des preuves
Les tests et la CI rapide contrôlent le code et les artefacts. Ils n'attestent pas la qualité d'un LLM réel. Les campagnes generation.json et robustness.json contiennent les résultats réels. Les champs human_* restent null ; revue_generation.csv est une revue assistée explicitement signalée. Le gate de promotion n'est pas abaissé pour masquer une erreur de génération.

Les campagnes initiales sont conservées dans MLflow et dans des fichiers « legacy_environment » ou « initial_format ». Les métriques de la comparaison finale sont liées à la configuration corrigée. Les latences proviennent d'un hôte partagé, avec des campagnes parfois concomitantes ; elles ne sont pas des performances garanties sur le poste de l'étudiant.
